# Голосовой ассистент Тимурка для библиотеки им. Аркадия Гайдара

Голосовой веб-ассистент, разработанный для использования в филиале библиотеки в качестве бота для приветствия посетителей, возрастной категории 4+. 
Предполагается, что веб-сервер будет размещён на Windows-ПК, предназначенном для посетителей библиотеки. В качестве устройства для подключения к веб-серверу библиотека намерена использовать небольшую интерактивную доску с сенсорными экраном и микрофоном на операционной системе Android. 

Сценарии использования (реализовано сейчас):
1. Тимурка отвечает на отвлечённые темы: ответ полностью формируется GigaChat;
2. Тимурка отвечает на вопросы о библиотеке: GigaChat дана инструкция не отвечать на вопрос и отправлять пользователя к сотрудникам библиотеки.

Сценарии использования (планируется):
1. Тимурка отвечает на отвлечённые темы: ответ полностью формируется GigaChat;
2. Тимурка отвечает на вопросы о библиотеке: GigaChat работает совместно с RAG-системы, ответы которой прикладываются как контекст к промпту для формирования итогового ответа.

## Get started
1. Установить базовые зависимости командой `pip install -r requirements.txt`;
2. Установить прочие зависимости для распознавания речи и озвучивания текста (см. `speech.py` и `voice_recognizer.py`);
3. Создать файл `.env` на основе `.env_template`;
4. Зарегистрировать аккаунт на https://developers.sber.ru/studio/login с помощью SberID (оплата для базового тарифа GigaChat API не требуется) и вставить в `.env` ключи GIGACHAT_CLIENT_ID и GIGACHAT_CLIENT_SECRET;
5. Добавить в директорию проекта модели для распознавания и озвучивания речи: https://cloud.mail.ru/public/wjjN/bVmqh5xG3
6. Запустить веб-сервер `app.py`

## О технологиях
- Веб-сервер: Flask
- LLM для формирования ответов: GigaChat
- Озвучивание текста: piper-tts
- Распознавание речи: Vosk
